## The line

> My calendar is furious with me — I keep giving it the cold shoulder, and now all my days are numbered.

## About

A one-line dad joke: the calendar gets the cold shoulder, and the punchline lands on "all my days are numbered." The program in `main.py` writes this line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
